# Evaluation: diet checker

Run on 2026-11-09 with `uv run python -m eval.run`. 30 requests ([cases.json](cases.json)), most with a deliberate trap ingredient that breaks the requested diet (e.g. honey for Vegan, soy sauce for Gluten-Free).
Each request runs through the full workflow twice: without and with the diet checker agent. Every recipe is then graded by an independent judge (`anthropic/claude-haiku-5.5`, a different model family than the app's model) and by the deterministic diet rules.
