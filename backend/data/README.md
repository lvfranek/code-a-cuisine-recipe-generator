# Recipe data

`recipes.jsonl` holds one recipe per line (schema: `RecipeRecord` in `core/schemas.py`).
It is generated by `uv run python -m ingest.run` and is the input for the vector index.

## Source and license

The recipes are adapted from the **[Wikibooks Cookbook](https://en.wikibooks.org/wiki/Cookbook:Table_of_Contents)**,
by Wikibooks contributors, via the dataset
[gossminn/wikibooks-cookbook](https://huggingface.co/datasets/gossminn/wikibooks-cookbook).

Changes: converted to structured JSON by an LLM (normalized ingredient names, units,
cuisine and diet tags, cleaned-up steps). Each record links to its original page in `source.url`.

This license applies to the recipe data in this folder only, not to the application code.
